## Website

The Codlont website is built with React, TypeScript, and Vite.

## Pages

- Home
- About
- Research
- Blog
- Contact
- Manager Login

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the website:

```bash
npm run build
```

## Deployment

This project is configured for GitHub Pages. The repository is expected to be named `Codlontcompany`.

Configure GitHub Pages in **Settings → Pages** and select **GitHub Actions** as the deployment source.

## Contact

Replace the placeholder contact email in the website source with your official company email.
